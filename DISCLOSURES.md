# Disclosures and Attributions

## Visual assets

- The beer-cheers Unicode art displayed in the command-line welcome banner was
  sourced from [Emoji Combos](https://emojicombos.com/cheers-ascii).
- The PUB'LISH text banner was generated using the
  [Text to ASCII Art Generator](https://www.asciiart.eu/text-to-ascii-art).

## Pub data

The Oxford pub dataset was compiled using information from:

- [Ben Gutteridge's Oxford Pub Guide](https://bengutteridge.github.io/pubs/),
  including pub names, areas, providers, and notes; and
- [Oxford Pub Guide](https://www.oxfordpubguide.co.uk/allpubs.html), including
  pub names, locations, and notes.

## Mapping

The interactive Oxford pub map was built using
[Leaflet](https://leafletjs.com/). Map tiles and geographic data are provided
by [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

## Documentation

The project documentation website was built using
[Sphinx](https://www.sphinx-doc.org/).

## Continuous integration

The GitHub Actions configuration and project structure were adapted from the
[Oxford Research Software Engineering CI course starter repository](https://github.com/OxfordRSE/ci_course_start).

## Distribution
