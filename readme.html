Pub’lish

Pub’lish is a Python-based application for exploring pubs in the Oxford area. Functionality includes pub-tracking, pub-crawl, and statistics to track your pub’lishes (visits to the pub)!

Installation & Requirements

  • Requires Python 3.12 or later

  • Use the package manager pip to install Pub’lish.

    python -m pip install --index-url https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ beer-app-adgarnier

Usage

Run the App


### Get a list of available commands:
Run ```--help``` or ``` command --help```.

Example commands:

Launch Open the interactive Oxford pub map in your browser. Use ‘launch –help’ for more information.

Load Add pubs to the map. Choose from all, visited, or unvisited pubs. You can also enter ‘load all’, ‘load visited’, or ‘load unvisited’. Use ‘load –help’ for more information.

Unload Remove the currently loaded pubs from the map. Use ‘unload –help’ for more information.

Search Search the loaded pubs using names, roads, locations, sponsors, or other keywords. Use ‘search –help’ for more information.

Visit Mark pubs as visited and see the pubs you have already visited. Use ‘visit –help’ for more information.

Stats Create a graph showing how many times you have visited each pub. Use ‘stats –help’ for more information.

Crawl Create your own pub crawl. Use ‘crawl –help’ for more information.

Quit Stop the map server and close PUB’LISH. ```
