beer_app.pub_crawl.create_pub_crawl(pubs: list[Pub], start: Pub, end: Pub, total_pubs: int, buffer_metres: float = 100) → list[Pub]¶

Select intermediate pubs for a crawl.

Randomly choose the requested number of pubs within the corridor between the starting and ending pubs.

Parameters:

  • pubs (list) – A list of pubs that sit in the corridor, created by pubs_in_buffer() above

  • start ('Pub' object) – The starting pub, specified by the user

  • end ('Pub' object) – The ending pub, specified by the user

  • total_pubs (integer) – The total number of pubs on the pub crawl, specified by the user

  • buffer_metres (float) – The buffer distance to create the corridor between start and end
